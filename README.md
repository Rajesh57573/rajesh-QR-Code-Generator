# QR Code Generator 🔗

A responsive QR Code Generator built using HTML, CSS, and JavaScript.

## ✨ Features
- Generate QR codes from text or URLs.
- Clean and responsive UI.
- Smooth animations and gradient background.

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## 🚀 How to Use
1. Visit the [QR Code Generator](https://rajesh-qr-code-generator.vercel.app).
2. Enter your text or URL.
3. Click **Generate QR Code**.
4. Scan the generated QR code to access your content.
